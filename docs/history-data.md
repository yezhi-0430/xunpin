“有效行”只表示解析结构通过，不表示文案事实正确、无夸大宣传或全部商品覆盖。200条是文案记录数，同标题的不同文案不能当作商品更新或独立商品。来源文件日期2019-05-13是页面标注的文件日期，不是样本逐条观测时间；导入时间另行记录。

本地样本ID由语料哈希、采样参数与原始行号组成，明确标为样本记录号，不冒充淘宝item_id。没有价格就不填零或推算优惠，没有时间就保持未知。历史样本保存在独立SQLite表，不写入正式/回放快照、事件、报价或运营任务。

## 真实DeepSeek验证

按原始行号排序后，取所保存样本的前两条，各发起一次真实请求，使用本地配置的deepseek-flash。模型只看到当前标题、描述及输出Schema，不附整个数据集，不调用外部工具。共享既有串行锁和每日20次预算；本轮增加2次HTTP尝试，当天累计16次，没有自动提高预算或追加重试。

[公开汇总记录](../artifacts/history-validation.json) 只含数量、哈希、状态与模型别名。含真实文本的详细结果、截图位于被忽略的artifacts/private，原始ZIP不放入项目公开候选文件。

成功记录展示文案声称的材质/防护卖点、使用场景和包邮承诺，建议先核实产品参数与物流条件。引用匹配只证明原文存在，不能保证发现中每个短语都由该片段充分支持；例如涉及“袋子破裂”的解释仍需对照完整原文人工复核。两个请求不构成准确率或独立质量评估。

## 本地复现

取得该文件并确认当前用途与模型处理范围后，在项目根目录运行：

```powershell
uv run python -m backend.history "$env:USERPROFILE\Downloads\item_desc_dataset.zip" --limit 200 --seed 9717 --allow-ai
uv run python run.py
```

`--allow-ai` 是明确允许这些标题/描述用于配置模型的本地开关，未传时默认禁止新模型请求。导入本身不调用网络或模型。相同ZIP、种子和数量重导入时，样本记录号稳定，已有分析不会清除。再次分析失败、受限或未配置时，保留此前成功解读，另记录最近尝试状态并在详情提示；不把失败当作新结论。改变采样参数创建另一个集合，列表显示最近导入集合。

仅从ZIP读取固定名称的文本成员，不extractall或执行文件；限制压缩包、成员大小和行长度，严格解码。流式扫描不把整个740MB文件读入内存，仅保存抽样记录。完整ZIP仍留在用户Downloads中，不复制或删除原文件。
