# 淘宝官方接入：账号条件与下一步

核对时间：2026-10-21。用户已确认没有自己的或可配合授权的店铺。目前已登录淘宝联盟和淘宝开放平台工作台；开放平台已展示测试应用及基础权限，尚未验证可用于本项目的商品数据查询权限。

## 开放平台工作台最新检查

已在登录后的开放平台“开发”页检查：进入时“我的应用”显示尚未创建应用。创建页提供淘宝购物小程序、商家经营工具、小程序插件、阿里生态 API 开放和内容创作工具。

商家经营工具下的“一站式电商后台”默认选中“仓储管理系统”。该类目提示身份不通过，原因是支付宝账号不是企业资质认证。这是该类目的实际校验结果，不能据此推断所有类目都禁止个人申请。

“千牛商家应用”类目页提供“获取测试应用”入口。打开后，平台展示了测试应用名称、AppID 和已获得的基础权限，包括打开商品详情页、商品 SKU 选择器、用户授权入口及小程序基础能力等。页面说明这些权限用于通过淘宝开发者工具进行开发体验。未将账号标识、应用标识或凭证写入仓库；核对截图仅保存在被 Git 忽略的 `artifacts/private/`。

当前可见权限列表未展示项目后端所需的商品详情数据查询接口。打开商品详情页属于页面交互能力，不能直接当成定时读取商品标题、价格、描述或评价的数据接口。测试应用入口可继续用于开发能力核验，但目前没有商品 API 成功请求或真实数据落库证据。

## 淘宝联盟账号检查

已在登录后的真实页面找到“推广管理 → 媒体备案管理”，当前显示首次选择备案类型。页面说明：自有平台是完全自有可控的推广阵地；他方平台是自己可管理经营的账号；无自有阵地特指通过流量采买直接推广官方物料。

用户确认目前只有面试 demo，没有实际推广阵地。因而尚没有可以按当前实际情况填写的媒体备案类型。没有代选类别、编造备案材料、提交媒体备案或创建联盟应用，也没有证据表明账号已取得商品 API 权限。已完成联盟注册不能标记为“官方数据已接入”。

当前阻塞点是这条接入流程的业务资格与应用权限，仍需平台确认是否存在适用于个人面试/开发验证场景的申请方式；或获得真实商家合作授权。沙箱或平台示例即使可用，也不作为真实公开商品获取的验收。

## 当前结论

项目现有 `taobao.item.seller.get` 路径尚不能实际联调：缺少应用证书、接口权限与商家授权。普通淘宝登录态不能替代 API 授权。不能把买家 Cookie 填进 `TAOBAO_SESSION`，也不能用文档里的示例证书请求真实商品。

该接口需要授权，见 [官方商品接口文档](https://developer.alibaba.com/docs/api.htm?apiId=24625&source=search)。

## 无店铺时可核查的官方候选

淘宝联盟提供商品查询能力，但它建立在联盟业务体系与应用权限上。[官方新手指南](https://developer.alibaba.com/docs/doc.htm?articleId=118970&docType=1&source=search&treeId=713) 描述的路径是：淘宝账号登录联盟、按实际业务入驻、媒体备案、创建 AppKey、申请对应权限。该文档更新时间为 2023-02-01，当前是否可申请须以账号控制台和平台答复为准。

候选 `taobao.tbk.item.info.upgrade.get` 文档列出了应用签名要求和不同业务场景参数；“不需要授权”指不需要用户 session，不代表无需应用或用途审查。见 [官方接口文档](https://developer.alibaba.com/docs/api.htm?apiId=64763)。

不能由存在此接口推断它允许本项目的品牌运营竞品监控，也不能推断能返回完整描述和评价。没有真实媒体或对应业务条件时，不编造备案资料，不随意选用不匹配的场景。旧版商品查询的官方 FAQ 还指出其商品范围限制，见 [官方常见问题](https://developer.alibaba.com/docs/doc.htm?articleId=118971&docType=1&treeId=713)；新版范围需另核实。

## 需要用户完成的账号检查

1. 使用自己的淘宝账号登录 [淘宝联盟](https://pub.alimama.com/)，查看是否已有联盟账号、媒体备案及 APPKEY 申请入口。此步骤先查看现状，无需立即注册、提交协议或付费。
2. 反馈能够申请的应用/媒体类型，以及实际可见的商品接口权限名称。不要把 AppSecret、授权 Token、手机号、身份证件或其他账号资料发到聊天。
3. 如需入驻或申请，按真实业务用途申报，并先确认监控场景、缓存、模型分析与字段范围是否获准。协议、身份材料和账号申请由用户自行确认。
4. 若该账号没有适用条件，官方接口路径继续标为未接通；可寻求真实商家授权或重新核验其他获准来源。不会为展示效果自动改成网页抓取。

## 取得权限之后的技术步骤

根据实际接口文档适配响应；凭证只保存在本地被 Git 忽略的配置中。先用一个获准商品执行一次只读请求，验证身份、字段、价格语义、错误响应与配额，再运行至少三个调度周期。只有真实成功记录落库后，界面才可以表示该来源已联通。

本次检查未提交生产应用或类目申请，未接受协议，未执行真实商品 API 调用。开放平台已展示测试应用信息，不能继续笼统写成“没有任何应用”，也不能标记为“官方商品数据已接通”。
