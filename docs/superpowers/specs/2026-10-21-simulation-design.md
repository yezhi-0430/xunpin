# 保留巡品界面接入Claude模拟数据

用户纠正误开的旧界面后，本轮以既有巡品工作台为唯一主界面。保留深绿侧栏、卡片、事件、运营任务和真实历史样本；不采用Claude旧页面。

不新增模式，将Claude数据库作为当前概览数据直接展示。只读导入时源库已有220商品、18告警、7策略和80分析，保存到独立state命名空间。正式0商品和回放4商品6事件及真实历史文本不改变。导入不调用网络/模型，不把模拟告警变成真实快照差异，不将随机收益或置信度作为有效预测。模拟策略仅显示原建议文本、待核实说明和无收益承诺；价格只标为构造标价，无优惠及到手价推断。列表20条分页，告警详情明确缺前后证据，支持查看导入的历史价格样例但不自动调用旧版随机分析。

首次进入概览直接展示导入数据，用简短来源文字说明。保留原有两项选择“当前数据”和“流程回放”，没有第三种模式；真实历史样本独立。保留原设计语言和现有组件。

根目录新增ASCII/CRLF start.bat与标准库launcher.py，使用本地.venv，启动原backend.app工厂于127.0.0.1:8000；依赖缺失、端口冲突明确失败，同实例已运行则打开原界面，不杀其他进程。支持--check与--no-browser。

以构造SQLite测试导入、幂等、隔离、来源标签及接口；启动器测试覆盖外部cwd/中文路径、重复实例、缺依赖/其他应用占端口。实际导入后核对数量、原DB哈希、旧记录和模型预算保持，再浏览器验证原巡品UI。禁止提交、推送或真实模型调用。
