# 公开数据候选核验

核验日期：2026-10-21。以下保留首轮筛选，并补记用户完成登录后的实际接入。天池9717已下载、抽样导入，已对两条真实标题/描述调用DeepSeek；Kaggle其他候选未导入。结论不是对Kaggle或天池全部数据集的判断。

## 本轮结论

天池9717已作为独立历史文本接入：全量2,129,187行可解析，固定种子抽样200条，数据与分析仅存本地忽略目录。两条真实文本请求一条通过、一条回退；详情见 [导入与验证记录](history-data.md)。它不具备本题连续价格、促销、评价变化所需的全部信息，正式监控保持关闭。

Kaggle API 的真实请求本轮已成功返回公开元数据。它证明数据目录可访问，不证明淘宝商品接口已接通。原始筛选摘要见 [元数据记录](../artifacts/public-dataset-metadata.json)，包含查询词、响应状态、公开数据集标识、发布时间和上传者声明的许可。不是全站穷尽检索，也不是数据内容质量评估。

## 天池9717的具体限制

浏览器实际页面顶部显示“CC-BY-SA-NC 4.0”，正文“遵循协议”则写“CC BY-NC 4.0”，两个标记不一致；不能用第三方摘要消除这项冲突。页面还有“完成学生认证，免审批下载”提示。实际下载要求先登录；用户登录后点击文件已成功下载，没有代填学生认证或申请、没有代为确认新协议。不能据提示推断所有账号必须是学生。当前限定本地非商用演示、保留来源与作者引用，不向GitHub分发原始样本及真实文本输出，其他用途仍需核对适用条件。

页面关联 [THUDM/KOBE](https://github.com/THUDM/KOBE)。作者仓库说明TaoDescribe有标题/描述训练、验证和测试文件，下载器指向清华云与Google Drive。没有执行仓库脚本、安装训练依赖或下载大包。仓库代码MIT许可不自动覆盖数据，使用前仍核对原数据许可、署名及具体用途。历史文本即使可以使用，也不应改写为今日采集或生成虚假的前后商品版本。

## 接入任何公开数据前的验收

1. 固定数据集标识、发布者、原始来源、许可版本与引用要求；区分代码许可和数据许可。
2. 记录真实字段、币种/价格含义、商品身份、原始观测时间和版本时间。目录更新时间只表示发布动作；下载时间只表示本地获取动作。
3. 只做数据实际支持的验证：单份文本可测试语义抽取；同一商品的连续真实快照才可测试历史变化；定期发布、适用范围明确的数据交付才可进一步验收定时获取。
4. 先校验编码、字段、重复、异常与来源范围，再按许可保存本地样本。原始数据不自动放入GitHub或外发模型；没有适用依据时本地样本与AI外发分别保持未验收。
5. 无新版本就记录“上游无更新”，不生成商品变化；有新版本还需检查原始观测时间。不得用“今天重新下载”刷新陈旧报价的有效期。

历史文本已采用独立表保存样本与分析，保留文件哈希、行号与引用，不虚构淘宝item_id。完整ZIP仍在用户Downloads目录，项目未解压整个文件或复制全部语料。后续公开或再分发前另核对许可范围，不由当前本地导入推导已经获准生产使用。
